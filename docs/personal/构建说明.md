# 从源码运行与构建

目标环境：Windows x64，CPython 3.13.14，能够运行 Tk。WebView2 测试另外需要 Microsoft WebView2 Runtime。

## 源码运行

创建虚拟环境，在其中安装 requirements-windows.lock，再安装本项目。执行 python -m personal_mcp gui。

依赖使用固定版本。Windows-MCP 的依赖包括 GPL 组件 fuzzywuzzy 与 Levenshtein；它们不改变各上游文件标注的许可证。公开仓库提供本项目源码与安装脚本，公开发布完整二进制集合前须一并准备各组件要求的许可和对应源码。不要把本机私有安装目录直接推送到 Git。

## 资源

resources/python 不提交到源码。build_portable.py 接收 --python-home，要求独立的完整 CPython 3.13.14 x64 目录，不能传虚拟环境目录。

运行 python scripts/prepare_assets.py，以固定版本和摘要下载 ripgrep 15.1.0 到 resources/bin，并使用 Playwright 1.63.0 下载 Chromium 到 resources/browsers。把 OpenAI 官方 tunnel-client 0.0.14 和同发行版的 LICENSE、NOTICE、licenses.txt、SPDX 文件放到 resources/tunnel-client。程序会校验隧道客户端和搜索程序的固定摘要。

运行 python scripts/build_portable.py --output release-private/UnifiedPersonalMCP --python-home <完整Python目录>。该命令为当前所有者生成干净的个人安装目录，随后可通过 --zip 生成迁移压缩包。它不复制开发环境、个人配置或状态文件。

## 验证

运行 pytest tests_personal tests_bf。真实桌面验证：先运行 scripts/build-fixture.ps1，再执行 python -m tests_personal.acceptance_local --output verification/live-新的编号。

桌面验收会启动受控的测试窗口；在已登录且可交互的 Windows 会话中运行。它不会创建、连接或切换任何真实 OpenAI 隧道。
