# Unified Personal MCP

把编码、Windows 桌面、浏览器和 WebView2 操作放到同一个程序，通过 OpenAI Secure MCP Tunnel 连接自己的 Windows 开发机。

## 配置和运行

1. 将整个程序目录解压到本机较短的路径。双击 UnifiedPersonalMCP.exe。
2. 工作区填写多个项目所在的父目录。每次工作时选择其中一个具体项目。
3. 私有目录放在工作区以外，建议使用界面的默认值。
4. 填写本设备独立的 OpenAI 隧道 ID，选择运行密钥文件，或填写已配置的环境变量名。密钥内容不会显示。
5. 保存配置，运行“检查配置”，启动本地服务，然后连接隧道。

每台设备使用自己的私有目录、隧道和运行密钥。在两台同时运行的设备上不要使用同一个隧道 ID。配置界面会拒绝与本机正在使用的隧道竞争。

## 客户端工作流

先通过 UnifiedTask 的 begin 选择具体项目，保存仅返回一次的 workflow_id，再 activate。后续编码、桌面和浏览器工具使用同一个 workflow_id。结束时调用 end，释放本工作流的资源。

一个具体项目同时只能有一个写入工作流。已完成请求用相同 request_id 查询原结果；结果为 unknown 时先观察实际状态，不自动重做保存、启动或点击。

SearchSession 支持渐进搜索。stop 停止搜索并保留结果，release 停止并释放单次搜索及其结果，供后续搜索复用名额；无需结束整个工作流。每个工作流最多保留两次搜索，整台主机最多四次。

## 应用配置

项目目录中的 .bf/apps/*.json 注册应用。可使用相对于配置文件的路径，例如 project_root 为 ../..、启动文件为 ../../build/app.exe。示例见源码 examples/personal。

启动桌面应用使用 LaunchApplication；App 保留切换和调整窗口功能。浏览器会话使用 BrowserSession。附加 WebView2 仅支持已经启用本机调试通道、能够证明进程归属的已注册应用。结束附加会话不会关闭原应用。

优先使用窗口工具；需要前台输入时显式启用前台回退。最小化窗口截图可能使用临时恢复，截图不保证反映应用最新业务状态，应同时使用结构化观察验证。

## 停止、迁移和恢复

点击停止或关闭窗口会清理本程序启动的资源。清理未完成时会显示错误并保留恢复记录。重启后不根据旧 PID 终止进程。排障信息保存在私有目录。

将整个程序目录复制到另一台 Windows x64 设备后重新配置即可。不要复制原设备的私有目录、运行密钥、浏览器会话或配置文件。WebView2 应用需要该设备已安装 Microsoft WebView2 Runtime。

## 当前验证边界

本地 HTTP 与客户端经 OpenAI 隧道连接是两个独立检查。可用性与未完成项见项目 verification.md。公开仓库不包含本机密钥、运行配置、浏览器用户数据、截图或运行状态。
