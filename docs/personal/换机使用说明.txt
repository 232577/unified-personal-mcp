Unified Personal MCP · Windows x64 完整运行包

一、在另一台电脑使用
1. 将整个 ZIP 复制到另一台 Windows 10/11 x64 电脑，完整解压到固定位置，例如 C:\Tools\UnifiedPersonalMCP。不要只复制 EXE，也不要在压缩包内直接运行。
2. 双击 UnifiedPersonalMCP.exe。新设备首次打开只需填写“OpenAI 隧道 ID”和“隧道运行 key”。运行 key 直接粘贴到密码框，不需要先保存成文件。
3. 默认启用完全控制和登录自动连接，可按需取消。点击“保存并连接”，程序会自动创建本机目录、保存配置并启动后台连接。
4. 进入控制台后，以“OpenAI 已连接”和实际运行版本为准；启动请求已提交不代表隧道一定在线。后台模式下可关闭控制台，服务继续运行。

二、客户端连接
在 OpenAI 客户端中，让对应插件绑定这台电脑填写的隧道，再刷新工具目录。更换本机配置不会自动修改云端插件绑定。
两台电脑同时使用时，各自使用独立隧道及其对应运行 key。同一条隧道迁移设备时，先正常停止旧设备的连接。

三、哪些东西已经包含
本包包含 Python、Chromium、代码搜索工具、OpenAI 隧道客户端及本工具需要的 Python 依赖。工具本体无需另装 Python 或 Node.js。
被开发项目需要的 Git、Node.js、编译器、数据库和项目依赖，仍按该项目需求安装。操作 WebView2 业务应用时，目标电脑需要 Microsoft Edge WebView2 Runtime；独立 Chromium 浏览器不依赖它。
桌面操作需保持 Windows 用户已登录，界面可交互。此程序不是跨平台或开机未登录前的系统服务。

四、本机配置与日志
配置和运行 key 保存在 %LOCALAPPDATA%\UnifiedPersonalMCP，不会写回运行包。
默认项目目录：%LOCALAPPDATA%\UnifiedPersonalMCP\projects；完全控制模式下可直接指定其他项目绝对路径。
日志目录：%LOCALAPPDATA%\UnifiedPersonalMCP\data。
service-status.json 是当前状态，tunnel.log 是隧道连接日志，startup.log 是最近一次首次向导后台启动输出。
再次双击 EXE 可查看状态和高级配置。高级窗口手工点击“启动本地服务”启动的进程由该窗口管理；关闭该窗口会停止它，与首次向导启动的独立后台模式不同。

五、交付边界
运行包不含原设备配置、隧道 key、登录凭据、浏览器用户资料或业务项目。请保持完整目录结构；启用自动启动后不要移动程序目录，需要移动时重新启用一次自启动。
程序会校验文件完整性。请不要向解压后的程序目录添加配置、日志或测试文件，以免自启动校验失败。
