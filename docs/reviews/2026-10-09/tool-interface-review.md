## 架构与兼容

- 新增 tool_presentation 仅处理当前实例的复制目录，不修改共享上游注册表、不参与授权和实际执行。
- 状态变更动作通过不可变名称映射进入共享 _workflow_action；不使用 eval、动态表达式或按调用方字符串选择任意函数。
- Registry、OperationJournal、工作流状态机与认证方式未改动。旧接口仍公布并明确兼容用途，不在客户端未迁移时删除旧能力。
- 目录数量从完整 53 增至 58；测试更新精确数量并检查具体新增名称，没有删除断言或放宽成大于零。

## 安全与真实性

- 新入口不接受 principal、action 或 approved 注入；只读工作流仍不能执行命令，跨所有者结束/释放仍拒绝。
- 恢复需要真实代次，旧凭据失效；新旧入口共享同一去重回执，避免两个接口重复派发。
- title 是 MCP 可选字段，一致性是本项目新增质量门槛；字符串 enum 的类型补充不把旧合法 schema 说成非法。
- 完全控制范围如实披露但不再混入没有路径参数的工具。普通通知与本地策略报告不冒充平台审批。
- 未加入 fake-readonly、强制平台批准、伪造认证方案、跨连接回放或自动重复执行。
- 本轮未执行截图、生产热替换、依赖升级/审计、安装包构建或 OpenAI 平台放行验收；BrowserSession 等其他混合动作仍是后续迁移事项。
