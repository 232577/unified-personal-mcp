## 本轮边界与修正

- 将项目版本与运行版本标识更新为 0.1.12，保留 58 工具的兼容设计。未改软件工厂业务工程、依赖版本、机主的权限模式或平台审批设置。
- 真实 Windows 计划任务缺失返回的外层 HRESULT 为 DISP_E_EXCEPTION，内部 scode 为 FILE_NOT_FOUND。识别内层已知错误，但不把权限拒绝或账户信息缺失当作无任务。
- COM 初始化改为明确记录本次引用是否成功取得；初始化模式冲突不能导致无条件 CoUninitialize。对应合成错误分支先失败后修复。
- 真实切换测试曾在保持一个 COM 代理并跨调用初始化/释放时发生原生访问异常。单改读取属性不足以解决；最终按生产的操作边界独立取得并释放 COM 对象，仅传递 Python 元数据后，真实启停和清理验证通过。未将 COM 模式冲突断言为该原生崩溃的唯一原因。

## 切换控制复核

`scripts/switch_managed_release.py` 是显式执行的一次性维护脚本，不是新增远程执行通道。候选与旧包目录分离；既有安装器检查全部清单、隔离启动并备份任务定义。切换脚本核对已有任务归属、配置、XML 和单实例策略；仅停止该任务，不按任意 PID 杀进程。

脚本必须等当前调用者工作流结束；出现无关工作流时停止，不结束它们。最后停止阶段使用数据库短事务防止新预约竞争。候选本地检查失败时尝试恢复原登记；外部修改、未知资源或新业务工作导致不安全时，不强行覆盖/停止。

`LOCAL_READY` 只是服务端本地观察结果，必须在切换后通过实际插件核对版本、目录与调用。客户端工具目录缓存与运行包版本分别验证，不将目录未刷新解释成服务必然没有更新。
