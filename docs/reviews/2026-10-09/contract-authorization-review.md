## 本轮复现与变更

- `personal_mcp/host.py` 原来使用发布目录的 readOnlyHint 决定工作流写权限与请求账本路径。在隔离夹具中改变内部标注后，只读文件读取被拒绝、合法命令错误进入 EXECUTION_ERROR，预期 READ_ONLY_WORKFLOW 的拒绝也变成 EXECUTION_ERROR。这里没有证明远程调用方可以修改标注，更没有将其描述为已经成功越权执行。
- 新增 `personal_mcp/tool_policy.py`，由代码中明确登记的策略决定运行时路径，未知工具拒绝。目录标注不再决定运行时授权或是否使用既有去重账本。
- 保留既有 SearchSession 的任务私有搜索控制规则，不以该例外授予文件或桌面写权限。该工具仍按包含状态变化的工具发布；本轮没有完成它的多动作拆分。
- 发布目录前校验名称、描述、schema、必填参数与布尔标注，检查已登记读写分类与本次复核的潜在效果。无效目录在 Runtime 资源初始化之前被拒绝，不发布猜测的契约。
- 修正 unified adapter 中的风险描述：write_stdin 非空输入可以触发命令侧覆盖或外部效果；Clipboard set 覆盖共享内容；完全控制模式的六个文件工具不再声称仅访问封闭项目。没有修改上游工具注册表，也没有变更设备权限模式。这些标注更保守，可能增加确认，不保证减少平台拒绝。
