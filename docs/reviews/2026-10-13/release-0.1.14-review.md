# 0.1.14 远程桌面与发布验证

本轮按用户选择，在现有 MCP 隧道内增加侧边操控台和自动刷新图像。没有连接 Remote Desktop Commander 的设备；上游公开源码比较沿用 [本轮来源复核](upstream-review.md)。另一台 local MCP 设备不可达，用户暂时不能操作该电脑，尚未更新。

## 改动与安全边界

- 新增 DesktopConsole 入口及四个仅供组件调用的接口，完整服务目录为 63 项；提供显示器/窗口画面、鼠标键盘、同窗口拖拽、按位置滚动、主动剪贴板和分块文件收发。
- 默认仅查看，用户开启操控后才接受输入；停止、失焦、目标变化、凭据轮换和超时撤销授权。逐段派发前再次检查，释放按键和鼠标的清理保留。
- 修复排队请求越过授权时限、迟到开启覆盖停止、凭据轮换后旧请求仍派发、恢复工作流时锁顺序反转，以及结果未知被错误记为失败等问题。未知副作用不自动重放。
- 修复后台窗口右键/双击语义、旧快照标签、焦点错误、截图坐标和资源清理；真实输入验收发现上游 Unicode 函数返回计数与文档不一致，新增本项目适配器分别核验按下/释放，不修改第三方安装文件。
- 文件传输限制大小、数量、配额与有效期，核验 SHA256，不覆盖文件、不跟随链接、不执行上传内容。仅清理已核实退出进程留下且身份匹配的过期缓存；不明缓存保留并报告错误。
- UI 使用固定版本 MCP Apps SDK 离线包与许可证。短期组件凭据仅经私有元数据传递，原工作流/后端/隧道密钥不进入页面；不新增公网服务，不修改平台审批设置。

实际运行包的本地认证 HTTP 画面往返为 **163.01–220.96 毫秒**（13 次）。真实 ChatGPT 组件观察到 **1566 与 1851 毫秒**的隧道请求往返；这两次观测不代表持续帧率。自动刷新还包含默认 1200 毫秒等待，不能把上述往返时间换算成连续视频 FPS。

本地原始证据位于 `verification/release-014-final.xml`、`release-014-final.log`、`release-014-bundled-desktop/result.json`、`release-014-integrity.json` 和 `release-014-switch/result.json`。切换时的 `platform_call_verified=false` 是切换阶段的真实记录；后续真实插件和用户确认是单独的宿主证据。原始日志、配置、桌面画面和秘密均不公开上传。

Ruff 与自有源码差异空白检查通过。完整暂存差异的检查发现第三方许可证原文有一处尾随空格和一处文件末尾空行，保留原文；未将这两处声称为全量空白检查通过。发布前常见 OpenAI/GitHub token 与私钥标记扫描无候选命中，但不等于完整秘密检测保证。独立 Inspector 旧 58 接口断言已同步为 63，并加入五个桌面接口存在性检查；该维护脚本不在运行包载荷内。

升级 ZIP 为 **562966 字节**，SHA256：`3a2a181fc1cfd0c4815b1b9e9ad3b6240703ed4a86e3cf9e48909ff017b7c8f4`。源码升级包支持完整 0.1.10–0.1.13 基线，不包含 Python、浏览器或其他第三方运行时。包内文档是构建时快照，本次发布后的验证记录以本仓库及 Release 说明为准；已核验的产品模块和 UI 资产未因补写记录而改变。

## 未覆盖与限制

真实 ChatGPT 宿主的显示/私有元数据链已经验证；没有在该宿主中操作用户业务桌面或验证最大文件保存体积。鼠标键盘及文件闭环使用真实本机隔离窗口与认证 HTTP 验收。混合 DPI 多显示器依赖映射测试，尚未在对应硬件组合验证。

本版是自动刷新图像，非连续视频；不支持跨窗口拖拽、标题栏拖动、Win 键组合、安全桌面/UAC/锁屏和无人登录前的桌面操作。Windows 可将第一次点击仅用于激活窗口，不自动补点。遇到焦点或权限拒绝时按明确错误停止，不保证未来所有操作均获平台放行。

本轮属于定向独立审查和回归，不是完整 Codex Security 扫描或全部依赖审计。0.1.13 报告所列上游跨平台通用套件限制仍适用。热更新实际为受控服务重启，会有短暂断线；另一台设备更新仍待其恢复连接。
